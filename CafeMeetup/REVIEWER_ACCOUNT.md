### What Reviewers Can Test

1. **Sign In**
   - Use the email/password above
   - Or use "Sign in with Apple" (creates new account)

2. **Discover Tab**
   - Swipe right to like users
   - Swipe left to pass
   - See match popup when mutual likes occur

3. **Matches Tab**
   - View all matched users
   - See unread message counts
   - Tap to open conversations

4. **Chat Features**
   - Send regular messages
   - Toggle priority messages (star icon)
   - Send virtual gifts (gift icon)
   - Use icebreaker questions (lightbulb icon)
   - See read receipts (checkmarks turn green when read)

5. **Blog Tab**
   - Create posts about coffee meetups
   - Comment on existing posts
   - View community content

6. **Map Tab**
   - See nearby users (blue = you, yellow = others)
   - Users within 5 miles who are recently active
   - Real-time location updates

7. **Profile Tab**
   - Edit profile information
   - Upload profile photo
   - View Account Settings
   - Access account deletion feature

### Pre-populated Test Data

The app includes several test users in the same city (Boise, Idaho) for demonstration:

### Notes for Reviewers

- **Location Services**: App requests location to show nearby users on map
- **Apple Sign In**: Fully functional for creating new accounts
- **Dark Mode**: All screens support dark mode
- **No Subscriptions**: App is completely free with no in-app purchases
- **Account Deletion**: Easily accessible through Profile → Account Settings
- **Data Privacy**: All data stored locally (no backend server yet)
